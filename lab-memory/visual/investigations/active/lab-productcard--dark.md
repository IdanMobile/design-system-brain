## Investigation — lab-productcard--dark / figma live

**Job ID:** manual  
**Date:** 2026-05-24T18:30:00.000Z  
**Source:** agent investigation

| Field | Value |

| Status | fail |

| Worst hotspot | 24.92% |
| Fail reason | global+hotspot |

### Root cause

The Storybook screenshot is taken with `waitUntil: "domcontentloaded"` (only waits for fonts via `fonts.ready`). The `<img>` element (`https://picsum.photos/seed/helmet/600/600`) has not finished loading when the screenshot fires, so the image area renders as the dark card background (#1F2937). The Figma renderer uses the `dataUrl` captured by the extractor (which uses `waitUntil: "networkidle"` and correctly captures the image), so Figma shows the forest photo while Storybook shows dark. This causes ~10.5% global diff concentrated in the left image area (region-01: 24.9%).

Secondary diffs (regions 2 & 3) are tiny (~0.4%, ~0.2%) and likely font anti-aliasing.

### Recommended fix area

`packages/pixel-test/src/figma-live-test.ts` — add a wait for `<img>` elements inside `[data-figma-component]` to finish loading before taking the Storybook screenshot (between `fonts.ready` and `addStyleTag`).
