# LLM Platform Plan

**Side project — not the storybook-to-figma-lab roadmap.**

This folder documents the **Universal Design Compiler** platform: any design source → UniversalLayer IR → pixel-verified targets (Figma, Storybook, design-system code, native) — developers wire **business logic only**.

The agent reads [`AGENTS.md`](./AGENTS.md) first, then follows [`GUIDELINES.md`](./GUIDELINES.md) and [`WORKFLOWS.md`](./WORKFLOWS.md).
