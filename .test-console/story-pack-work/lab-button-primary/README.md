# @lab/story-lab-button-primary

Semantic React delivery for `lab-button--primary` — real `@lab/ui` components (`Button`).

Install peer dependency:

```bash
pnpm add @lab/ui
pnpm add ./component.tgz
```

```tsx
import "@lab/ui/styles.css";
import { Button, defaultStoryArgs } from "@lab/story-lab-button-primary";

<Button {...defaultStoryArgs} />
```
